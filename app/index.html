Sync zwischen Geräten

Die Daten werden vor dem Hochladen mit dem Passwort verschlüsselt (AES-256) und als Datei in einem privaten GitHub-Repo abgelegt. Jedes Gerät mit denselben drei Angaben erhält denselben Stand; Änderungen auf mehreren Geräten werden Eintrag für Eintrag zusammengeführt. Ohne Passwort sind die Online-Daten verloren. Token: GitHub → Settings → Developer settings → Fine-grained tokens, nur dieses Repo, „Contents: Read and write“.
